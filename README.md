# Guideline Reminder

A Visual Studio Code extension with checklists and reminders for design and development work.

## Download and install

1. Go to the repository's [Releases page](../../releases).
2. Open the latest release and download the `.vsix` file under **Assets**. For the current version, this is `guideline-reminder-0.0.9.vsix`.
3. Open Visual Studio Code.
4. Open the Command Palette:
   - macOS: `Cmd + Shift + P`
   - Windows/Linux: `Ctrl + Shift + P`
5. Run **Extensions: Install from VSIX...**.
6. Select the downloaded `.vsix` file.
7. Reload VS Code if prompted.

You can also install the latest package directly from the [latest release](../../releases/latest).

## Find and use the extension

After installation, open the Command Palette and search for **Guideline Reminder**. Available commands include:

- **Guideline Reminder: Open Checklist**
- **Guideline Reminder: Start Design Check**
- **Guideline Reminder: Open Best Practices for Current Phase**

> This extension is currently distributed through GitHub Releases. It will not appear in the Visual Studio Code Extensions Marketplace search yet.
