# Guideline Reminder

Eine VS-Code-Erweiterung mit Checklisten und Erinnerungen für Design- und Entwicklungsarbeit.

## Installation

1. Lade die aktuelle Datei `guideline-reminder-0.0.7.vsix` unter [Releases](../../releases) herunter.
2. Öffne in VS Code die Befehlspalette (`Cmd/Ctrl + Shift + P`).
3. Wähle **Extensions: Install from VSIX...** und wähle die heruntergeladene Datei aus.

## Nutzung

Öffne die Befehlspalette und suche nach **Guideline Reminder**.
